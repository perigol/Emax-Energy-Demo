# UI

Backoffice sobrio de una asesoría energética. Fondo `#f3f0e8`, lateral `#1e2a24`, acento `#c4a35a`, tarjetas blancas, cifras en tabular nums. Fraunces para la marca y Manrope para la interfaz.

Copia en español, frases cortas. Cada listado vacío explica qué falta y cómo crearlo. El banner de demo dice que los datos se reinician con el seed.

El PDF de la factura lleva logo si existe, razón social, NIF, domicilio, número, cliente, líneas, base, IVA y total. El pie indica que es una muestra y no una factura presentada ante la Agencia Tributaria.

No uses paleta violeta genérica ni iconos decorativos sin función.
